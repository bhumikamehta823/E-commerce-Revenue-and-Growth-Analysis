# E-commerce Revenue and Growth Analysis

## Project Overview

This project focuses on analyzing e-commerce sales data using Microsoft Excel to understand revenue trends, customer purchasing behaviour, product performance, and customer satisfaction.

An interactive Excel dashboard was developed using Pivot Tables, Pivot Charts, and Slicers to present business insights in an easy-to-understand visual format.

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Slicers
- Data Cleaning and Analysis
- Data Visualization

## Key Performance Indicators (KPIs)

- Total Orders
- Total Quantity Sold
- Total Revenue
- Average Customer Rating
- Average Delivery Days

## Key Analysis

### 1. Sales Performance
Analyzed weekly quantity and revenue trends over the last 13 weeks to understand sales performance.

### 2. Customer Purchasing Behaviour
Examined customer preferences across different purchasing channels, including App, Instagram, Partner App, Target.com, and Website.

### 3. Purchase Frequency
Analyzed how frequently customers place orders to understand purchasing patterns.

### 4. Product Performance
Identified popular product categories and examined product preferences across different gender groups.

### 5. Geographical Analysis
Explored customer distribution across geographical locations to understand regional purchasing patterns.

### 6. Shipping Analysis
Analyzed the number of days taken to ship orders to understand delivery performance.

### 7. Customer Satisfaction
Evaluated customer ratings across different months to understand customer satisfaction levels.
